# iOS Publish Action — Portable Generation Guide

> **Audience:** an AI coding agent (or a human) working in **any** repository that contains an iOS app.
> **Goal:** generate a GitHub Actions workflow `.github/workflows/ios-publish.yml` that builds the iOS app,
> signs it for the App Store and uploads it to TestFlight, plus the helper script
> `.github/scripts/ios-signing.py`, and tell the repo owner exactly which secrets to add.
>
> Copy this file into the target repo (or paste it into the agent prompt) and say:
> *"Follow `IOS_PUBLISH_ACTION_GUIDE.md` to create the iOS publish action for this repo."*

---

## 0. Rules for the agent

1. **Inspect before writing.** Complete Section 1 (detection) and write down the answers before generating any file.
2. **Never commit secrets.** No keys, `.p8`, `.p12`, passwords, team IDs or issuer IDs in the repo — only `${{ secrets.X }}` references.
3. **Manual signing only.** Do **not** use `-allowProvisioningUpdates` / automatic signing in CI. With it, Xcode tries to create a
   *development* certificate on every fresh runner, which eventually fails with
   *"Your account has reached the maximum number of certificates"*. The signing script below creates the distribution
   certificate and profile **once** and reuses them afterwards.
4. **Don't `pip install` into the runner's system Python.** macOS runners use Homebrew Python, which is "externally managed"
   (PEP 668) and rejects global installs. Use a virtualenv (already done in the template).
5. **Ask the owner** only for things you cannot discover: the bundle ID if ambiguous, which scheme/target is the shipping app,
   and whether app extensions exist that also need profiles.
6. When done, report back: detected stack, files created, the secrets table (Section 5), and the first-run checklist (Section 7).

## 1. Detect the project

Run these from the repo root and record the results.

### 1.1 Find the iOS project

```bash
# Xcode projects/workspaces (ignore dependencies)
find . -path ./node_modules -prune -o -path '*/Pods' -prune -o -path '*/build' -prune -o \
  \( -name '*.xcworkspace' -o -name '*.xcodeproj' \) -print | grep -v 'project.xcworkspace'
# Project generators / package managers
ls Package.swift Podfile Cartfile Project.swift project.yml 2>/dev/null
find . -maxdepth 3 \( -name Podfile -o -name project.yml -o -name Project.swift \) -not -path './node_modules/*'
```

### 1.2 Decide the stack (first match wins)

| Signal in repo | Stack | Kind | iOS project location (typical) |
|---|---|---|---|
| `package.json` has `expo` dependency **and** no committed `ios/` dir (or `app.json`/`app.config.*` with `expo` key) | **Expo (managed / CNG)** | Cross-platform (JS/TS) | generated by `npx expo prebuild` → `<app>/ios/` |
| `package.json` has `react-native` and a committed `ios/` dir with `Podfile` | **React Native (bare)** | Cross-platform (JS/TS) | `ios/<Name>.xcworkspace` |
| `pubspec.yaml` with `flutter:` | **Flutter** | Cross-platform (Dart) | `ios/Runner.xcworkspace`, scheme `Runner` |
| `capacitor.config.(ts\|json)` or `@capacitor/ios` dependency | **Capacitor / Ionic** | Cross-platform (web) | `ios/App/App.xcworkspace` (CocoaPods) or `ios/App/App.xcodeproj` (SPM), scheme `App` |
| `*.csproj` with `net*-ios` target framework | **.NET MAUI / .NET iOS** | Cross-platform (C#) | built by `dotnet publish`, not `xcodebuild` |
| `settings.gradle(.kts)` + `iosApp/` + `shared/` or `composeApp/` | **Kotlin Multiplatform / Compose MP** | Cross-platform (Kotlin) | `iosApp/iosApp.xcodeproj` |
| `.xcodeproj`/`.xcworkspace` only, or `project.yml` (XcodeGen) / `Project.swift` (Tuist) | **Native iOS** | Native | the project/workspace itself |

If the repo is a monorepo, the iOS app may live in a subfolder (`mobile/`, `apps/ios/`, …). Use that folder as `APP_DIR`.

### 1.3 Detect the language (native and for documentation)

```bash
SWIFT=$(find . -name '*.swift' -not -path '*/Pods/*' -not -path '*/node_modules/*' -not -path '*/.build/*' | wc -l)
OBJC=$(find . \( -name '*.m' -o -name '*.mm' \) -not -path '*/Pods/*' -not -path '*/node_modules/*' | wc -l)
echo "swift=$SWIFT objc=$OBJC"
```

| Stack | App language |
|---|---|
| Native | Swift if `swift > objc`, else Objective-C (mixed is fine — build is identical) |
| Expo / React Native | JavaScript/TypeScript (+ generated Swift/ObjC++ host) |
| Flutter | Dart |
| Capacitor / Ionic | HTML/CSS/JS (+ Swift host) |
| .NET MAUI | C# |
| KMP / Compose MP | Kotlin (+ Swift host) |

### 1.4 Collect build facts

```bash
# Schemes, targets, configurations (run on the workspace if one exists, else the project)
xcodebuild -list -workspace <path>.xcworkspace   # or: -project <path>.xcodeproj
# Bundle ID and Info.plist of the app target
xcodebuild -showBuildSettings -workspace <ws> -scheme <scheme> -configuration Release 2>/dev/null \
  | grep -E ' (PRODUCT_BUNDLE_IDENTIFIER|INFOPLIST_FILE|IPHONEOS_DEPLOYMENT_TARGET|DEVELOPMENT_TEAM) '
```

If Xcode isn't available locally, read them from source instead:
- Expo: `app.json` → `expo.ios.bundleIdentifier`; the prebuild project/scheme name is the `expo.name` with non-alphanumerics removed.
- React Native / native: `grep -r PRODUCT_BUNDLE_IDENTIFIER *.xcodeproj/project.pbxproj`.
- Flutter: `ios/Runner.xcodeproj/project.pbxproj`. Capacitor: `capacitor.config.*` → `appId`.
- Also look for app extensions (widgets, notification service): extra targets with their own bundle IDs → see Section 8.

Write down: `STACK`, `APP_DIR`, `WORKSPACE_OR_PROJECT`, `SCHEME`, `TARGET`, `BUNDLE_ID`, `INFOPLIST_FILE`, node/flutter/java/dotnet versions (from `.nvmrc`, `package.json#engines`, `.fvmrc`, `pubspec.yaml`, `global.json`).

## 3. Workflow template

Replace every `<PLACEHOLDER>`. Insert the stack-specific **Prepare** steps from Section 4 where marked.
`.NET MAUI` replaces the *Configure signing → Export IPA* steps entirely (see 4.6).

```yaml
name: iOS — Archive → TestFlight

on:
  workflow_dispatch:
  # push:
  #   tags: ['ios-v*']

concurrency:
  group: ios-publish
  cancel-in-progress: false

jobs:
  build-and-distribute:
    name: Xcode Build → TestFlight
    # App Store uploads require a recent SDK. Use the newest macOS image that ships the required Xcode.
    runs-on: macos-26
    timeout-minutes: 90
    env:
      BUNDLE_ID: <BUNDLE_ID>                       # e.g. com.company.app
      XC_CONTAINER: <-workspace path/App.xcworkspace | -project path/App.xcodeproj>
      XC_PROJECT: <path/App.xcodeproj>             # project file that contains the app target
      SCHEME: <SCHEME>
      TARGET: <TARGET>                             # app target name (usually == SCHEME)

    steps:
      - uses: actions/checkout@v4

      - name: Select newest Xcode
        run: |
          XC=$(ls -d /Applications/Xcode_*.app 2>/dev/null | sort -V | tail -1)
          [ -n "$XC" ] && sudo xcode-select -s "$XC"
          xcodebuild -version

      # ───── Stack-specific PREPARE steps go here (Section 4) ─────
      # They must leave a buildable .xcworkspace/.xcodeproj at $XC_CONTAINER with Pods installed.

      - name: Create build keychain
        run: |
          KEYCHAIN_PATH=$RUNNER_TEMP/build.keychain
          security create-keychain -p "" "$KEYCHAIN_PATH"
          security default-keychain -s "$KEYCHAIN_PATH"
          security list-keychains -d user -s "$KEYCHAIN_PATH" $(security list-keychains -d user | tr -d '"')
          security unlock-keychain -p "" "$KEYCHAIN_PATH"
          security set-keychain-settings -lut 21600 "$KEYCHAIN_PATH"
          echo "KEYCHAIN_PATH=$KEYCHAIN_PATH" >> "$GITHUB_ENV"

      - name: Set up App Store Connect API key
        env:
          ASC_KEY_ID: ${{ secrets.ASC_API_KEY_ID }}
          ASC_KEY_CONTENT: ${{ secrets.ASC_API_KEY_CONTENT }}
        run: |
          mkdir -p ~/.appstoreconnect/private_keys
          KEY_FILE="$HOME/.appstoreconnect/private_keys/AuthKey_${ASC_KEY_ID}.p8"
          if printf '%s' "$ASC_KEY_CONTENT" | grep -q "BEGIN PRIVATE KEY"; then
            printf '%b' "$ASC_KEY_CONTENT" > "$KEY_FILE"          # raw PEM (handles literal \n)
          else
            printf '%s' "$ASC_KEY_CONTENT" | base64 --decode > "$KEY_FILE"   # base64 of the .p8
          fi
          openssl pkey -in "$KEY_FILE" -noout 2>/dev/null \
            || { echo "::error::ASC_API_KEY_CONTENT is not a valid .p8 key"; exit 1; }
          echo "ASC_KEY_PATH=$KEY_FILE" >> "$GITHUB_ENV"

      - name: Set up signing (reuse or create-once certificate + profile)
        env:
          ASC_KEY_ID: ${{ secrets.ASC_API_KEY_ID }}
          ASC_ISSUER_ID: ${{ secrets.ASC_API_KEY_ISSUER_ID }}
          CERTIFICATE_P12_BASE64: ${{ secrets.IOS_CERTIFICATE_P12_BASE64 }}
          CERTIFICATE_PASSWORD: ${{ secrets.IOS_CERTIFICATE_PASSWORD }}
          GH_PAT: ${{ secrets.GH_PAT }}
        run: |
          # Homebrew Python is externally managed (PEP 668) → use a throwaway venv.
          VENV="$RUNNER_TEMP/signing-venv"
          python3 -m venv "$VENV"
          "$VENV/bin/pip" install --quiet --disable-pip-version-check pyjwt cryptography requests
          "$VENV/bin/python" .github/scripts/ios-signing.py

      - name: Configure app target signing (manual, distribution)
        env:
          TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
        run: |
          gem install xcodeproj --no-document
          ruby - <<'EOF'
          require 'xcodeproj'
          project = Xcodeproj::Project.open(ENV['XC_PROJECT'])
          target  = project.targets.find { |t| t.name == ENV['TARGET'] } or raise "Target #{ENV['TARGET']} not found"
          target.build_configurations.each do |c|
            c.build_settings['CODE_SIGN_STYLE'] = 'Manual'
            c.build_settings['DEVELOPMENT_TEAM'] = ENV['TEAM_ID']
            c.build_settings['CODE_SIGN_IDENTITY'] = 'Apple Distribution'
            c.build_settings['CODE_SIGN_IDENTITY[sdk=iphoneos*]'] = 'Apple Distribution'
            c.build_settings['PROVISIONING_PROFILE_SPECIFIER'] = ENV['PROFILE_NAME']
          end
          attrs = (project.root_object.attributes['TargetAttributes'] ||= {})
          attrs[target.uuid] ||= {}
          attrs[target.uuid]['ProvisioningStyle'] = 'Manual'
          attrs[target.uuid]['DevelopmentTeam'] = ENV['TEAM_ID']
          project.save
          EOF

      - name: Set build number (highest uploaded + 1)
        env:
          ASC_KEY_ID: ${{ secrets.ASC_API_KEY_ID }}
          ASC_ISSUER_ID: ${{ secrets.ASC_API_KEY_ISSUER_ID }}
        run: |
          # TestFlight rejects a CFBundleVersion that is not higher than the last upload. Don't use
          # github.run_number: builds uploaded earlier (EAS, Xcode, another workflow) may already be higher.
          BUILD_NUMBER=$("$RUNNER_TEMP/signing-venv/bin/python" .github/scripts/ios-build-number.py)
          PLIST=$(xcodebuild -showBuildSettings $XC_CONTAINER -scheme "$SCHEME" -configuration Release 2>/dev/null \
                  | awk -F' = ' '/ INFOPLIST_FILE /{print $2; exit}')
          PLIST_PATH="$(dirname "$XC_PROJECT")/$PLIST"
          # Info.plist may hold a literal CFBundleVersion (Expo prebuild writes one) — overwrite it.
          /usr/libexec/PlistBuddy -c "Set :CFBundleVersion $BUILD_NUMBER" "$PLIST_PATH"
          echo "Build number: $BUILD_NUMBER"
          echo "BUILD_NUMBER=$BUILD_NUMBER" >> "$GITHUB_ENV"

      - name: Write ExportOptions.plist
        env:
          TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
        run: |
          cat > "$RUNNER_TEMP/ExportOptions.plist" <<EOF
          <?xml version="1.0" encoding="UTF-8"?>
          <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
          <plist version="1.0"><dict>
            <key>method</key><string>app-store-connect</string>
            <key>teamID</key><string>${TEAM_ID}</string>
            <key>signingStyle</key><string>manual</string>
            <key>signingCertificate</key><string>Apple Distribution</string>
            <key>uploadSymbols</key><true/>
            <key>provisioningProfiles</key><dict>
              <key>${BUNDLE_ID}</key><string>${PROFILE_NAME}</string>
            </dict>
          </dict></plist>
          EOF

      - name: Archive
        run: |
          set -o pipefail
          xcodebuild archive $XC_CONTAINER \
            -scheme "$SCHEME" -configuration Release -sdk iphoneos \
            -destination "generic/platform=iOS" \
            -archivePath "$RUNNER_TEMP/App.xcarchive" \
            CURRENT_PROJECT_VERSION="$BUILD_NUMBER"
          # NOTE: deliberately no -allowProvisioningUpdates (see guide §0 rule 3)

      - name: Export IPA
        run: |
          xcodebuild -exportArchive \
            -archivePath "$RUNNER_TEMP/App.xcarchive" \
            -exportOptionsPlist "$RUNNER_TEMP/ExportOptions.plist" \
            -exportPath "$RUNNER_TEMP/export"
          ls "$RUNNER_TEMP/export"/*.ipa

      - name: Upload to TestFlight
        env:
          ASC_KEY_ID: ${{ secrets.ASC_API_KEY_ID }}
          ASC_ISSUER_ID: ${{ secrets.ASC_API_KEY_ISSUER_ID }}
        run: |
          # altool finds the key in ~/.appstoreconnect/private_keys/AuthKey_<ID>.p8
          xcrun altool --upload-app -t ios -f "$(ls "$RUNNER_TEMP"/export/*.ipa | head -1)" \
            --apiKey "$ASC_KEY_ID" --apiIssuer "$ASC_ISSUER_ID"

      - name: Clean up keychain
        if: always()
        run: security delete-keychain "$RUNNER_TEMP/build.keychain" || true
```

## 4. Stack-specific PREPARE steps

Insert these right after **Select newest Xcode**. Each must end with an Xcode project that builds.

### 4.0 CocoaPods code-signing patch (any stack that uses CocoaPods)

Pod targets must not be signed with the app's profile. Add this inside the Podfile's `post_install do |installer|` block
(commit it for bare RN / native / Flutter / Capacitor; patch it at CI time for Expo, whose Podfile is generated):

```ruby
installer.pods_project.targets.each do |target|
  target.build_configurations.each do |config|
    config.build_settings['CODE_SIGNING_ALLOWED'] = 'NO'
    config.build_settings['CODE_SIGNING_REQUIRED'] = 'NO'
  end
end
```

CI patch step (Expo) — inserts the block before `react_native_post_install(`:

```yaml
      - name: Patch Podfile — disable code signing for Pod targets
        run: |
          python3 - <<'EOF'
          import sys
          path = '<APP_DIR>/ios/Podfile'
          s = open(path).read()
          if 'CODE_SIGNING_ALLOWED' in s: sys.exit(0)
          anchor = 'react_native_post_install('
          if anchor not in s: sys.exit('anchor not found in Podfile')
          patch = """
              installer.pods_project.targets.each do |target|
                target.build_configurations.each do |config|
                  config.build_settings['CODE_SIGNING_ALLOWED'] = 'NO'
                  config.build_settings['CODE_SIGNING_REQUIRED'] = 'NO'
                end
              end
          """
          open(path, 'w').write(s.replace(anchor, patch + '    ' + anchor, 1))
          EOF
```

(`python3` with only the standard library is fine on the runner — PEP 668 only blocks `pip install`.)

## 5. Secrets and keys the owner must add

Add them under **GitHub repo → Settings → Secrets and variables → Actions → New repository secret**.

| Secret | Required | What it is | How to get it |
|---|---|---|---|
| `ASC_API_KEY_ID` | ✅ | App Store Connect API key ID (10 chars) | App Store Connect → **Users and Access → Integrations → App Store Connect API** → *Team Keys* → **+** → role **App Manager** (or Admin). Copy the **Key ID**. |
| `ASC_API_KEY_ISSUER_ID` | ✅ | Issuer ID (UUID) | Same page, shown above the keys table. |
| `ASC_API_KEY_CONTENT` | ✅ | The `.p8` private key | **Download API Key** (only possible once!). Paste the full file contents including `-----BEGIN PRIVATE KEY-----`, **or** `base64 -i AuthKey_XXXX.p8 \| pbcopy`. |
| `APPLE_TEAM_ID` | ✅ | 10-char Team ID | developer.apple.com → **Account → Membership details**. |
| `IOS_CERTIFICATE_P12_BASE64` | ⚠️ see below | Apple **Distribution** certificate + private key, base64 | Keychain Access → *My Certificates* → right-click **Apple Distribution: <Team>** (must show a private key underneath) → **Export…** → `.p12` with a password → `base64 -i cert.p12 \| pbcopy`. |
| `IOS_CERTIFICATE_PASSWORD` | ⚠️ with the above | Password used when exporting the `.p12` | — |
| `GH_PAT` | Optional | Fine-grained token with **Secrets: Read and write** on this repo | Lets the script store a newly created certificate into the two secrets above. Only needed on the very first run when no distribution certificate exists. |

**Choosing a certificate path:**
- **You already have an Apple Distribution certificate** (most accounts) → export it as `.p12` and set `IOS_CERTIFICATE_P12_BASE64` + `IOS_CERTIFICATE_PASSWORD`. `GH_PAT` not needed.
- **No distribution certificate exists in the account** → leave both certificate secrets empty and set `GH_PAT`. The first run creates one and saves it to the repo secrets; later runs reuse it.
- **A certificate exists but nobody has its private key** → revoke it at developer.apple.com → *Certificates*, then use the previous bullet. (The script refuses to create a second one silently.)

**Apple-side prerequisites (owner):**
1. Paid Apple Developer Program membership.
2. The **bundle ID** is registered: developer.apple.com → *Identifiers* (with the capabilities the app uses, e.g. Push Notifications).
3. An **app record** exists in App Store Connect → *Apps* → **+ New App** with that bundle ID (upload fails otherwise).
4. Export compliance: set `ITSAppUsesNonExemptEncryption` = `NO` in Info.plist (Expo: `ios.infoPlist`) if applicable, or answer in App Store Connect after upload.

App-specific runtime secrets (e.g. `GoogleService-Info.plist`, API base URLs) are separate — list any the app needs in the report and write them to files in a step before the build.

## 6. Signing script — `.github/scripts/ios-signing.py`

Copy verbatim. It is idempotent: it **reuses** the certificate in `IOS_CERTIFICATE_P12_BASE64` (verified by serial number against
the Apple account) and an active App Store profile containing it; it creates either **only if missing**. It writes
`PROFILE_NAME` / `PROFILE_UUID` to `$GITHUB_ENV` for later steps.

```python
#!/usr/bin/env python3
"""Idempotent iOS signing setup for CI.

Creates an App Store distribution certificate and provisioning profile ONLY if
they do not already exist for this app; otherwise reuses them.

Env: ASC_KEY_ID, ASC_ISSUER_ID, ASC_KEY_PATH, BUNDLE_ID, RUNNER_TEMP, KEYCHAIN_PATH,
     GITHUB_ENV, CERTIFICATE_P12_BASE64 (optional), CERTIFICATE_PASSWORD,
     GH_PAT + GITHUB_REPOSITORY (only needed to store a newly created cert)
"""
import base64, os, plistlib, subprocess, sys, time
import jwt, requests  # pip install pyjwt cryptography requests

API = "https://api.appstoreconnect.apple.com/v1"
E = os.environ
tmp = E["RUNNER_TEMP"]
keychain = E["KEYCHAIN_PATH"]
password = E.get("CERTIFICATE_PASSWORD") or "ci-p12-password"


def run(*cmd, **kw):
    return subprocess.run(cmd, check=True, **kw)


def api(method, path, **kw):
    token = jwt.encode(
        {"iss": E["ASC_ISSUER_ID"], "exp": int(time.time()) + 600, "aud": "appstoreconnect-v1"},
        open(E["ASC_KEY_PATH"]).read(), algorithm="ES256", headers={"kid": E["ASC_KEY_ID"]})
    r = requests.request(method, API + path, headers={"Authorization": f"Bearer {token}"}, timeout=60, **kw)
    if not r.ok:
        sys.exit(f"::error::ASC API {method} {path} -> {r.status_code}: {r.text}")
    return r.json()


def import_p12(path):
    run("security", "import", path, "-k", keychain, "-P", password, "-T", "/usr/bin/codesign")
    run("security", "set-key-partition-list", "-S", "apple-tool:,apple:", "-k", "", keychain,
        stdout=subprocess.DEVNULL)


def p12_cert_pem(path):
    pem = subprocess.run(["openssl", "pkcs12", "-in", path, "-nokeys", "-passin", f"pass:{password}",
                          "-legacy"], capture_output=True, text=True)
    if pem.returncode:  # OpenSSL 1.x / LibreSSL has no -legacy flag
        pem = subprocess.run(["openssl", "pkcs12", "-in", path, "-nokeys", "-passin", f"pass:{password}"],
                             capture_output=True, text=True, check=True)
    return pem.stdout


def p12_serial(path):
    out = subprocess.run(["openssl", "x509", "-noout", "-serial"], input=p12_cert_pem(path),
                         capture_output=True, text=True, check=True).stdout
    return out.strip().split("=")[1].upper()


def p12_describe(path):
    return subprocess.run(["openssl", "x509", "-noout", "-subject", "-enddate"], input=p12_cert_pem(path),
                          capture_output=True, text=True, check=True).stdout.strip()


def list_certs():
    # DISTRIBUTION = "Apple Distribution" (current); IOS_DISTRIBUTION = legacy "iPhone Distribution".
    return api("GET", "/certificates?filter[certificateType]=DISTRIBUTION,IOS_DISTRIBUTION&limit=200")["data"]


def create_cert():
    if not E.get("GH_PAT"):
        sys.exit("::error::No distribution certificate secret and no GH_PAT to store a new one. "
                 "Add GH_PAT (repo secrets write) or provide IOS_CERTIFICATE_P12_BASE64.")
    if list_certs():
        sys.exit("::error::A distribution certificate already exists in the Apple account but its private "
                 "key is not available. Set IOS_CERTIFICATE_P12_BASE64 to its .p12 (or revoke it) - "
                 "refusing to create another.")
    key, csr = f"{tmp}/dist.key", f"{tmp}/dist.csr"
    run("openssl", "req", "-new", "-newkey", "rsa:2048", "-nodes", "-keyout", key, "-out", csr,
        "-subj", f"/CN={E['BUNDLE_ID']} CI Distribution/O=CI")
    body = {"data": {"type": "certificates", "attributes": {
        "certificateType": "DISTRIBUTION", "csrContent": open(csr).read()}}}
    data = api("POST", "/certificates", json=body)["data"]
    cer, pem, p12 = f"{tmp}/dist.cer", f"{tmp}/dist.pem", f"{tmp}/cert.p12"
    open(cer, "wb").write(base64.b64decode(data["attributes"]["certificateContent"]))
    run("openssl", "x509", "-inform", "der", "-in", cer, "-out", pem)
    run("openssl", "pkcs12", "-export", "-inkey", key, "-in", pem, "-out", p12, "-passout", f"pass:{password}")
    b64 = base64.b64encode(open(p12, "rb").read()).decode()
    gh_env = {**E, "GH_TOKEN": E["GH_PAT"]}
    repo = E["GITHUB_REPOSITORY"]
    run("gh", "secret", "set", "IOS_CERTIFICATE_P12_BASE64", "--repo", repo, "--body", b64, env=gh_env)
    run("gh", "secret", "set", "IOS_CERTIFICATE_PASSWORD", "--repo", repo, "--body", password, env=gh_env)
    print("Created new distribution certificate and stored it in repo secrets.")
    return p12, data["id"]


# --- certificate -----------------------------------------------------------
if E.get("CERTIFICATE_P12_BASE64"):
    p12 = f"{tmp}/cert.p12"
    open(p12, "wb").write(base64.b64decode(E["CERTIFICATE_P12_BASE64"]))
    serial = p12_serial(p12).lstrip("0")
    certs = list_certs()
    cert_id = next((c["id"] for c in certs
                    if c["attributes"]["serialNumber"].upper().lstrip("0") == serial), None)
    if not cert_id:
        print(f"Certificate in secret: {p12_describe(p12)}, serial={serial}")
        print("Distribution certificates in the Apple account:")
        for c in certs:
            a = c["attributes"]
            print(f"  - {a.get('certificateType')} '{a.get('name')}' serial={a['serialNumber'].upper().lstrip('0')} "
                  f"expires={a.get('expirationDate')}")
        sys.exit("::error::The certificate in IOS_CERTIFICATE_P12_BASE64 is not an active distribution "
                 "certificate in this Apple account (revoked/expired?). Remove the secret to have a new one created.")
    print("Reusing existing distribution certificate.")
else:
    p12, cert_id = create_cert()
import_p12(p12)

# --- provisioning profile ---------------------------------------------------
bundle = E["BUNDLE_ID"]
bid = api("GET", f"/bundleIds?filter[identifier]={bundle}&limit=200")["data"]
bid = next((b for b in bid if b["attributes"]["identifier"] == bundle), None)
if not bid:
    sys.exit(f"::error::Bundle ID {bundle} is not registered in the Apple developer account.")

# This related-resource endpoint rejects filter[...] params, so filter client-side.
profiles = api("GET", f"/bundleIds/{bid['id']}/profiles?limit=200")["data"]
profile = None
for p in profiles:
    if p["attributes"]["profileType"] != "IOS_APP_STORE" or p["attributes"]["profileState"] != "ACTIVE":
        continue
    certs = api("GET", f"/profiles/{p['id']}/certificates?limit=200")["data"]
    if any(c["id"] == cert_id for c in certs):
        profile = p
        break
if profile:
    print("Reusing existing provisioning profile.")
else:
    profile = api("POST", "/profiles", json={"data": {
        "type": "profiles",
        "attributes": {"name": f"CI App Store {bundle} {int(time.time())}", "profileType": "IOS_APP_STORE"},
        "relationships": {
            "bundleId": {"data": {"type": "bundleIds", "id": bid["id"]}},
            "certificates": {"data": [{"type": "certificates", "id": cert_id}]}}}})["data"]
    print("Created new provisioning profile.")

raw = base64.b64decode(profile["attributes"]["profileContent"])
decoded = subprocess.run(["security", "cms", "-D"], input=raw, capture_output=True, check=True).stdout
info = plistlib.loads(decoded)

os.makedirs(dest, exist_ok=True)

with open(E["GITHUB_ENV"], "a") as f:
    f.write(f"PROFILE_NAME={info['Name']}\nPROFILE_UUID={info['UUID']}\n")
```

### 6.1 Build number script — `.github/scripts/ios-build-number.py`

Prints the highest `CFBundleVersion` already uploaded to App Store Connect for the app, plus one. Runs in the venv
created by the signing step.

```python
#!/usr/bin/env python3
"""Print the next iOS build number (CFBundleVersion) for CI.

Asks App Store Connect for the highest build number already uploaded for the app
and prints that + 1, so TestFlight never rejects the upload as a duplicate.

Env: ASC_KEY_ID, ASC_ISSUER_ID, ASC_KEY_PATH, BUNDLE_ID
"""
import os, sys, time
import jwt, requests  # pip install pyjwt cryptography requests

API = "https://api.appstoreconnect.apple.com/v1"
E = os.environ


def api(path):
    token = jwt.encode(
        {"iss": E["ASC_ISSUER_ID"], "exp": int(time.time()) + 600, "aud": "appstoreconnect-v1"},
        open(E["ASC_KEY_PATH"]).read(), algorithm="ES256", headers={"kid": E["ASC_KEY_ID"]})
    r = requests.get(API + path, headers={"Authorization": f"Bearer {token}"}, timeout=60)
    if not r.ok:
        sys.exit(f"::error::ASC API GET {path} -> {r.status_code}: {r.text}")
    return r.json()


bundle = E["BUNDLE_ID"]
apps = [a for a in api(f"/apps?filter[bundleId]={bundle}&limit=200")["data"]
        if a["attributes"]["bundleId"] == bundle]
if not apps:
    sys.exit(f"::error::No App Store Connect app record for {bundle}. Create it under Apps -> New App.")

highest = 0
for b in api(f"/builds?filter[app]={apps[0]['id']}&sort=-uploadedDate&limit=200")["data"]:
    version = b["attributes"]["version"]  # CFBundleVersion, e.g. "36"
    if version.isdigit():
        highest = max(highest, int(version))

print(f"Highest uploaded build number: {highest}", file=sys.stderr)
print(highest + 1)
```

## 8. Troubleshooting (real failures and their fixes)

| Error | Cause | Fix |
|---|---|---|
| `error: externally-managed-environment` on `pip3 install` | Homebrew Python, PEP 668 | Install into a venv (template already does). |
| `Your account has reached the maximum number of certificates` / `No profiles for '<bundle>' were found … App Development` | `-allowProvisioningUpdates` + automatic signing makes Xcode create dev certs | Remove the flag; use manual signing (Configure step) with the script's profile. Revoke stale dev certs if needed. |
| `The certificate in IOS_CERTIFICATE_P12_BASE64 is not an active distribution certificate` | `.p12` is revoked/expired/from another team, **or** the script only searched legacy `IOS_DISTRIBUTION` certs | Use the script above (searches `DISTRIBUTION` too). Compare the logged serial with the account list; re-export the right cert. |
| `filter[profileType] can not be used with this request` (`PARAMETER_ERROR.ILLEGAL`) | Related endpoint `/bundleIds/{id}/profiles` rejects filters | Filter client-side (script above does). |
| `Bundle ID … is not registered` | Identifier missing | Register it at developer.apple.com → Identifiers. |
| `openssl pkcs12 … mac verify failure` | Wrong `IOS_CERTIFICATE_PASSWORD` | Fix the secret. |
| `ASC_API_KEY_CONTENT is not a valid .p8 key` | Truncated paste / wrong encoding | Paste the whole PEM or base64 of the file. |
| `No signing certificate "Apple Distribution" found` | Cert not in the build keychain search list, or legacy "iPhone Distribution" cert | Keychain step adds it to the list; for a legacy cert set identity to `iPhone Distribution` in Configure + ExportOptions. |
| Pods fail with signing errors | Pods inherit signing | Podfile patch (4.0). |
| `IPHONEOS_DEPLOYMENT_TARGET is set to 9.0` warnings | Old pods | Harmless warning. |
| Upload: `The bundle version must be higher than the previously uploaded version: 'N'` (409, `ENTITY_ERROR.ATTRIBUTE.INVALID.DUPLICATE`) | CFBundleVersion not set, or set from `github.run_number`, while earlier uploads already reached N | *Set build number* step with `ios-build-number.py` (highest uploaded + 1), written into Info.plist **and** passed as `CURRENT_PROJECT_VERSION`. |
| Upload: `No suitable application records were found` | App record missing in App Store Connect | Create the app record (Section 5, prerequisite 3). |
| SDK-version rejection on upload | Old Xcode image | Use the newest `macos-*` runner with the required Xcode. |

**App extensions** (widget, notification service, …): each extension target has its own bundle ID and needs its own App Store
profile. Run the signing script once per bundle ID (set `BUNDLE_ID` per run and capture `PROFILE_NAME` under a different env
name), apply the Configure step per target, and add each `bundle → profile` pair to `provisioningProfiles` in ExportOptions.
